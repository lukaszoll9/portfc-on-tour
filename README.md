# 🟠 Port FC on Tour

> A fan-driven sticker & community campaign for Port FC Bangkok — spotted worldwide.

![Port FC on Tour](assets/og-image.png)

## What is this?

Port FC on Tour is a grassroots community movement inspired by campaigns like **Danke Max** and **Köln 5096**. We print QR stickers, drop them at expat spots, Thai restaurants, fan bars, airports, and city walls around the world — and build a global Port FC community through Instagram reposts.

**Every scan lands on this page. Every post gets reposted.**

---

## The concept

```
Fan prints sticker
       ↓
Sticker gets dropped (hostel / bar / gym / airport)
       ↓
Someone scans QR code
       ↓
Lands on portfc-tour.netlify.app
       ↓
Tags @portfc_tour on Instagram
       ↓
Gets reposted → community grows
```

---

## Sticker formats

| Format | Size | Use case |
|--------|------|----------|
| Round | 7cm diameter | Bottles, laptops, helmets |
| Landscape | 10 × 6 cm | Walls, doors, windows |
| Street tag | 15 × 5 cm | Lampposts, skate spots, walls |

All sticker files are in `/sticker-designs/` as print-ready SVGs and PDFs.

## Deploy to Netlify

1. Fork this repo
2. Connect to [Netlify](https://netlify.com)
3. Deploy — no build step needed, it's pure HTML

Or drag & drop the folder into Netlify's deploy dashboard.
